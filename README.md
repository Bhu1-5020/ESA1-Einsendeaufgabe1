# Himalaya Coffee House

This project is part of _ESA 1 - Einsendeaufgabe 1 : Meine erste Website_
Frontend Development course at FernFH

## Technologies

- HTML
- Tailwind Css
- TypeScrip
- Git

## Features

- Menu created with TypeScript
- Greeting message created with TypeScript

## How to run

### clone the repository

```bash
git clone <repository url>
# open the project folder
cd <project folder>
npm install -g typescript
tsc -v
tsc script.ts --watch
```
